# 变电站背题

面向 iPhone 的纯本地离线题库练习工具。

- 从 Excel 导入多份单选、多选、判断题题库，并随时切换
- 题目乱序与选项乱序
- 答对后可延时 0.3 或 0.5 秒自动进入下一题，答错停留
- 点击底部进度打开题号导航，并用颜色标记答对、答错和未答
- 全屏左滑下一题、右滑上一题，并带平滑切题动画
- 点击错题查看原题号和题干，可单题进入或练习全部错题
- 小、中、大三档答题字体与紧凑行距
- 错题重练和本地学习统计
- 题库、错题和学习记录仅保存在当前设备
- 无账号、无云数据库、无数据上传

打开 GitHub Pages 地址后，可在 iPhone Safari 中选择“共享 → 添加到主屏幕”。首次完整打开后即可离线使用。
